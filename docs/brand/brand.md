Estrategia de compañía, producto y oportunidades YC 2026
1. Arquitectura de marca
INPROGRESS CO.

Rol:
Compañía de tecnología especializada en soluciones basadas en datos para el deporte y el rendimiento humano.

Concepto

InProgress representa una idea central:

El rendimiento nunca está terminado. Siempre está en progreso.

La compañía desarrolla herramientas que permiten capturar, organizar, interpretar y utilizar datos deportivos.

Territorio

Sports + Data + Technology + Performance

Propósito

Convertir datos deportivos en conocimiento útil para mejorar el rendimiento.

Visión

Construir un ecosistema tecnológico que permita a deportistas, preparadores físicos, entrenadores, equipos y organizaciones comprender su rendimiento a través de sus propios datos.

Misión

Desarrollar soluciones digitales que conecten entrenamiento, datos e historial de rendimiento para facilitar mejores procesos de planificación, seguimiento y toma de decisiones.

3. Concepto de CYCLES

CYCLES representa la naturaleza cíclica del entrenamiento de alto rendimiento.

El atleta no progresa mediante sesiones aisladas. Su evolución ocurre mediante ciclos:

PLAN → TRAIN → MEASURE → ANALYZE → ADAPT → REPEAT

Cada ciclo genera nuevos datos.

Cada nuevo dato aporta contexto.

Ese contexto permite tomar mejores decisiones.

Y esas decisiones construyen el siguiente ciclo.

Concepto central

Every cycle builds the next.

4. Idea central de marca

Una frase estratégica para CYCLES:

Performance is a cycle.

No es una sesión.

Es el resultado de múltiples ciclos acumulados a través del tiempo.

20. Dynamic Software Interfaces

YC plantea software que pueda adaptarse dinámicamente mediante agentes de IA según las necesidades del usuario.

Aplicación en CYCLES

Un preparador físico podría solicitar:

CYCLES podría construir dinámicamente el análisis.

Otro ejemplo:

¿Qué atletas presentan una caída de rendimiento respecto de su promedio de las últimas cuatro semanas?

El sistema genera automáticamente la visualización y análisis.

Esto convierte CYCLES de un conjunto de dashboards en una:

Interfaz de inteligencia sobre el rendimiento.
